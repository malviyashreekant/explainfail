# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion focused on making the project
better. Harassment, personal attacks and discrimination are not welcome.

To report a problem, use GitHub's private "Report a vulnerability" form on the Security tab, or
contact the maintainer through their GitHub profile (`malviyashreekant`). Reports are handled
privately.
